# ගණිත ලෝකය — Sinhala Mathematics Learning Website

මෙය O/L සහ සාමාන්‍ය ගණිතය සිංහලෙන් ඉගෙනීමට නිර්මාණය කළ responsive වෙබ් අඩවියකි.

## ඇතුළත් විශේෂාංග
- Premium dark theme සහ light mode
- CSS 3D rotating cube animation
- ගණිත මාතෘකා කාඩ්පත්
- සෙවුම සහ කාණ්ඩ තේරීම සහිත සූත්‍ර පුස්තකාලය
- වෘත්ත, ත්‍රිකෝණ, පයිතගරස්, ප්‍රතිශත සහ වර්ගජ සමීකරණ ගණක
- කෙටි ප්‍රශ්න සහ පිළිතුරු ප්‍රතිචාර
- Mobile / tablet / desktop responsive layout

## VS Code තුළ ධාවනය
1. ZIP ගොනුව Extract කරන්න.
2. VS Code විවෘත කර `ganitha_lowak` ෆෝල්ඩරය විවෘත කරන්න.
3. `index.html` ගොනුව browser එකෙන් විවෘත කරන්න. පහසුම ක්‍රමය VS Code හි **Live Server** extension එක භාවිතා කිරීමයි.
4. අන්තර්ජාල සම්බන්ධතාවයක් තිබේ නම් Sinhala font එක load වේ. අනෙක් ක්‍රියාකාරීත්වයන් සඳහා build step එකක් අවශ්‍ය නැත.

## GitHub Pages වෙත නොමිලේ publish කිරීම
1. GitHub හි අලුත් public repository එකක් සාදන්න (උදා: `ganitha-lowak`).
2. `index.html`, `style.css`, `script.js`, `README.md` ගොනු repository එකේ root එකට upload කරන්න.
3. Repository → **Settings** → **Pages** වෙත යන්න.
4. **Deploy from a branch** තෝරන්න.
5. Branch ලෙස `main`, folder ලෙස `/(root)` තෝරා **Save** කරන්න.
6. GitHub Pages ලබාදෙන URL එකෙන් වෙබ් අඩවිය විවෘත කරන්න.

## අන්තර්ගතය පිළිබඳ සටහන
මෙහි ඇතුළත් සූත්‍ර සහ උදාහරණ ප්‍රධාන ගණිත මාතෘකා ආරම්භ කිරීමට සකස් කළ මූලික පුස්තකාලයකි. මෙය සෑම ශ්‍රේණියකම සම්පූර්ණ නිල විෂය නිර්දේශය හෝ සියලුම O/L පාඩම් ආවරණය කරන බවට සහතිකයක් නොවේ. පාඩම් හා සූත්‍ර ඔබේ භාවිත කරන පෙළපොත/විෂය නිර්දේශය සමඟ පරීක්ෂා කරන්න.
